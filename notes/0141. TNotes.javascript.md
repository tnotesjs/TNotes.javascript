## 1. 导读

本节内容：对 TNotes.javascript 知识库的简单介绍。

TNotes.javascript 是一个基于 [tnotes][1] 实现的一个 javascript 开源知识库。

接下来主要会在这个知识库中记录一些和 JS、HTML、CSS 相关的知识点。

## 2. 学习建议

- 先做到对 JS 有个初步认知即可，初学阶段没必要围绕某个细节问题去深挖，否则会很容易陷进去，阻塞后续的学习进程。
- 随着后续的学习，再逐步加深对 JS 的了解，再一点点去深入原理。
